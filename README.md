# C Language Practice

这个仓库记录我的 C 语言基础练习和早期小程序实践。它不是主力作品集仓库，但能展示我在指针、数组、函数拆分、文件组织和小项目实现上的学习轨迹。

## 这个仓库看什么

| 方向 | 内容 |
| --- | --- |
| 语法基础 | 函数、数组、字符串、结构体、指针 |
| 程序组织 | 多文件、头文件、模块拆分、简单工程结构 |
| 控制台练习 | 输入输出、条件判断、循环、菜单交互 |
| 小型项目 | 超市管理系统、打字练习、五子棋等早期综合练习 |

## 为什么保留它

嵌入式开发绕不开 C。这个仓库保留的是基础训练痕迹，重点不是“项目复杂”，而是持续练习这些底层能力：

- 指针和数组的使用习惯。
- 函数拆分和模块化意识。
- 用简单数据结构组织程序状态。
- 从单文件练习过渡到小型工程。

## 推荐阅读顺序

1. `0.函数-数组-字符串/`：看基础语法和字符串处理。
2. `1.pointer/`、`Pointer/`：看指针练习。
3. `超市管理系统/`：看菜单式控制台程序和文件/数据组织思路。
4. `五子棋/`、`打字练习系统/`：看早期小项目的交互逻辑。

## 说明

这个仓库包含一些 Visual Studio 生成文件和历史练习产物。真正值得看的部分是各目录下的 `main.c`、`test.c` 以及少量项目源码文件。
