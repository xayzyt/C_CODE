# C Language Practice

C 语言基础练习和小项目记录。

![C](https://img.shields.io/badge/C-00599C?style=flat-square&logo=c&logoColor=white)
![Visual Studio](https://img.shields.io/badge/Visual_Studio-5C2D91?style=flat-square&logo=visualstudio&logoColor=white)

## 内容

- 函数、数组、字符串
- 指针
- 结构体
- 多文件工程
- 控制台输入输出
- 简单菜单程序
- 早期小项目练习

## 目录示例

| 目录 | 内容 |
| --- | --- |
| `0.函数-数组-字符串/` | 基础语法练习 |
| `1.pointer/`、`Pointer/` | 指针练习 |
| `超市管理系统/` | 控制台管理程序 |
| `五子棋/` | 五子棋练习 |
| `打字练习系统/` | 打字练习程序 |

## 说明

- 主要代码在各目录的 `main.c`、`test.c` 或 `main.cpp` 中。
- 仓库包含 Visual Studio 工程文件和部分编译输出。
